# World Map Mondrian

## Overview
World Map Mondrian is a creative project inspired by the art style of Piet Mondrian. The goal of this project is to experiment with the CSS Grid layout to create a world map representation in Mondrian's iconic style.

## Tech Stack
- **HTML**
- **CSS Grid**

## Project Goal
The primary objective of this project is to explore the capabilities of CSS Grid by designing a visually appealing and abstract world map influenced by Mondrian's geometric patterns and color scheme.

---

Feel free to explore and modify the code to learn more about CSS Grid and creative web design!
